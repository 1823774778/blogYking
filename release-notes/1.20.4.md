# 博客 1.20.4 · 歌单化音乐面板与播放失败跨源接续

这一版把前台音乐浮窗的“榜单”彻底改成“歌单”，并让播放失败的歌曲自动到其他平台寻找真正同名、同歌手的版本。

## 前台音乐面板

- 移除原来的平台标签行，顶部导航只保留“歌单”，不再以平台列表作为主入口。
- 当前音源声明的每个可榜单平台生成一张歌单卡片；卡片以宫格展示，桌面和手机均为两列，最后一张自动横跨整行。
- 歌单卡片显示封面或渐变色占位、歌单名、内容类型与歌曲数量，不再要求先选平台再看榜单。
- 点击卡片进入歌单详情：返回歌单、封面与标题、刷新、播放全部，以及 20 首歌曲列表。
- 打开弹窗时不再预加载榜单；进入具体歌单才请求歌曲，减少首次打开等待。
- 切换音源时歌单卡片、当前歌单与缓存同步更新；原歌单不存在时自动退回歌单宫格。
- 搜索、本地音乐、播放队列与歌单视图共用同一套返回与状态恢复逻辑。

## 播放失败自动接源

- 新增 `GET /api/music/fallback?title=&artist=&source=`：排除当前音源，并行搜索其余已声明且可播放的平台，最多等待 18 秒。
- 匹配规则收紧为“原始歌名归一化后完全相等 + 歌手集合匹配”：`Live`、`黑胶版`、`网友改编`、`合唱版` 等附加版本不会被当作原曲；候选歌手多出或缺少成员时也不会自动接源。
- 原歌曲先尝试当前音质，再降级到 128K；当前平台解析失败或音频加载失败时，依次尝试候选平台的 320K / 128K 地址。
- 候选播放成功后才替换歌曲的来源、ID、封面、专辑、时长与音质信息；队列中的歌曲标题和歌手保持不变，避免播放到同名不同歌手的版本。
- 只有全部候选都失败时才提示“无法播放”，不会在同源反复重试，也不会静默失败。

## 验证记录

- 六音音源 1.2.1：平台为酷我 / 酷狗 / 企鹅 / 网易 / 咪咕，歌单宫格 5 张卡片在桌面 1440px 与手机 390px 均无横向溢出。
- 点击“酷我音乐热歌”进入 20 首歌曲详情，返回、刷新、播放全部与播放队列切换正常。
- 实测“如愿 / 王菲”：酷我 320K、128K 均返回 400，自动切换到企鹅音乐 128K，音频接口返回 `206 audio/mpeg` 并持续播放。
- 严格匹配实测：`起风了` 候选 5 条、`平凡之路` 4 条、`我不难过` 6 条、`慌啥子嘛` 2 条；Live、黑胶、网友改编、合唱版与多歌手版本均被剔除。
- 后端 `mvn test`、`mvn -DskipTests package` 通过；前端 `npm run build` 通过；播放器桌面与手机截图验收通过。

## 已知情况

- 长青 SVIP 音源 1.3.0 的上游音频后端 `yinyue.haitang.net` 仍返回 HTTP 522，属于音源服务端故障，本站无法替代其解析。
- 歌单卡片当前对应“当前音源可用的平台榜单”，不是音源内部任意自建歌单；歌单标题由前端按平台能力映射。
