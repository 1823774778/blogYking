# 博客 1.13.0

## 后台模块扩展：角色权限、公告 AI、主题与个人中心

参考 MIT 许可项目 [lingview/dim_stack](https://github.com/lingview/dim_stack) 的后台信息架构，按本站 Vue 3 + Spring Boot 架构重做，不直接嵌入 React。

### 角色与用户

- 新增角色实体、内置角色种子与角色管理接口：角色编码、名称、描述、权限目录、启用状态、内置标记。
- 内置 ADMIN、USER、EDITOR 三个角色；ADMIN 自动拥有全部权限。
- 新增权限目录与逐项授权界面，权限覆盖仪表盘、个人中心、用户、角色、文章、评论、标签、公告、主题、站点、设置、存储与通知。
- 登录鉴权同时授予 `ROLE_<code>` 与 `PERM_<permission>`，后台入口改为权限 `system:admin`。
- 用户管理改为独立接口，支持分页搜索、角色筛选、新增用户、编辑邮箱/昵称/密码/角色/头像/手机/性别/生日、封禁/解封与禁言。
- 禁止禁用自己，禁止降级或禁用最后一个启用管理员。
- 用户资料新增手机号、性别、生日；个人中心可修改邮箱并同步登录账号，改邮箱要求当前密码。

### 公告与 AI

- 新增公告管理页：启用开关、标题、跳转链接、Markdown 编辑与前台效果预览、图片插入、保存。
- 首页新增公告横幅，可点击跳转到指定文章或链接。
- 新增「AI 生成公告」按钮与弹窗：填写要点、选择语气、可编辑本次提示词，生成结果回填正文，发布前人工确认。
- AI 设置新增「AI 公告」能力开关与默认提示词；关闭能力后接口直接拒绝。
- 新增 `POST /api/admin/ai/generate-announcement`。

### 主题管理

- 新增主题库页面，内置墨记、纸白、青瓷、海盐、绯红、深夜 6 套主题。
- 提供迷你页面预览、色板、当前主题标记与一键应用。
- 主题写入站点配置 `themePreset`，应用后前台与后台同步刷新；浅色/深色主题自动切换明暗，墨记跟随系统。

### 站点信息与前台

- 站点信息新增首页主标题、首页副标题，留空自动回退站点名称与描述。
- 新增「高级与代码」标签页：公安备案号、自定义 Head、自定义 Footer。
- 页脚渲染自定义页脚与备案号，自定义 Head 在页面加载时注入。
- 仪表盘快捷操作新增公告与 AI、主题管理、角色权限入口。

### 文章编辑

- 全屏 Markdown 编辑器新增文章分类、文章别名与评论区开关。
- 别名仅允许小写字母、数字、连字符与下划线；关闭评论的文章会拒绝新评论。
- 文章设置抽屉保留摘要、标签、封面、状态、置顶与 AI 摘要。

### 个人中心

- 重做个人中心：头像上传、昵称、登录邮箱、手机号、性别、生日、个人简介、账号安全与账号信息。
- 按需求移除 API Key 管理，不提供第三方密钥托管入口。

### 验证

- 后端 Maven 编译与前端 Vite 构建通过。
- 测试站完成首次初始化，实际打开仪表盘、主题、公告、角色、用户、个人中心、站点信息、AI 设置与新建文章页。
- 主题切换、公告保存、角色创建/更新/删除、用户列表接口完成冒烟验证。
- AI 公告接口在测试站 AI 未配置时返回明确未启用提示，不发起外部请求。
