# 博客 1.20.0 · 播放器体验与音源模式

这次更新集中修复站点音乐的播放失败，并把前台播放器改成跟随悬浮球位置展开的形态，同时让音乐内容严格跟随后台选择的模式。

## 播放修复

- 新增同源音频代理 `GET /api/music/audio`：平台音频先由服务端带上正确的 Referer / User-Agent 拉取，再转发给浏览器。
- 解决平台防盗链、短时 token、`http` 音频在 `https` 站点被混合内容拦截导致的「音乐无法播放」。
- 代理支持 `Range`，播放器可以正常拖动进度、继续播放。
- 前端播放地址优先使用代理；音频加载失败时自动重新请求一次播放地址，再失败才提示。
- 播放失败提示区分本地文件与在线音源，不再把浏览器自动播放限制误报成音频失效。

## 音乐模式

- 后台「本地音乐 / 音源导入」切换会立即保存并刷新前台，不再只是后台页面的视觉切换。
- 本地音乐模式：前台播放器只显示「本地音乐 / 播放列表」。
- 音源导入模式：前台不再显示本地音乐，只显示音源可用的「榜单 / 搜索 / 播放列表」。
- 移除音源后没有在线能力，前台自动退回本地音乐。
- 新增站点配置 `musicContentMode`，默认 `source`，旧站点无音源时仍自动显示本地音乐。

## 播放器交互

- 去掉悬浮球左侧的迷你播放条，只保留悬浮球入口。
- 桌面端鼠标悬停悬浮球自动展开；触屏设备点击展开。
- 手机端按悬浮球在屏幕左 / 右半区，分别从左侧或右侧滑入播放器。
- 播放器展开位置由悬浮球位置计算：拖到右上角向左下展开，拖到左下角向右上展开；空间不足时自动收缩宽度和高度。
- 播放器展开时悬浮球淡出隐藏，收起时重新出现。
- 播放中悬浮球封面旋转，外圈虚线环同步转动，并保留均衡器跳动；暂停后停止旋转。
- 播放器展开/收起增加基于悬浮球一侧的位移和缩放动效，并遵循系统“减少动效”设置。
- 面板不再单独拖动，位置完全跟随悬浮球。

## 榜单

- 榜单平台只读取音源声明的平台，不再无条件补一个固定网易云。
- 音源没有声明任何可支持平台时，前台不显示榜单标签。
- 榜单入口由「热歌榜」改为「榜单」，标题使用接口实际返回的榜单名，不再是固定热歌榜。
- 平台标签保留音源声明顺序；默认选中更稳定的网易云 / QQ 解析通道，避免首次点击落在不可用平台。

## 升级说明

- 版本号升级至 `1.20.0`。
- 新增配置键 `musicContentMode`，首次启动自动补默认值 `source`。
- 新增公开接口 `GET /api/music/audio`；`GET /api/music/url` 响应新增 `proxyUrl`，原 `url` 字段保留。
- 音频代理由本站签发短时令牌，只允许转发已经由音源解析出的地址，不开放任意 URL 代理。
- 代理使用流式响应，应用已把 MVC 异步超时提高到 30 分钟，避免长音频被截断。

## 验证记录

- 桌面 1440×900：悬停悬浮球展开，悬浮球隐藏；默认面板在左下，拖到右上后向左下展开。
- 手机 390×844：右侧悬浮球从右滑入，左侧悬浮球从左滑入，面板占满可用宽度。
- 播放网易云榜单曲目，`audio.currentSrc` 为本站 `/api/music/audio`，播放中；拖动到 120 秒后继续播放。
- 模拟首次返回坏代理地址：前端自动重新请求 `/api/music/url`，第二次成功播放。
- 本地音乐模式仅显示「本地音乐 / 播放列表」，本地曲目可播放。
- 音源模式不显示本地音乐标签；平台列表来自音源声明，无可用平台时榜单标签隐藏。
- 后台切换模式立即写入配置，刷新后仍保持当前模式。
- 前端 `npm run build`、后端 `mvn test` 与 `mvn -DskipTests package` 均通过。
