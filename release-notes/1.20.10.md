# 博客 1.20.10 · 竖音量圆点对齐与四平台音源播放修复

- 修复竖音量条的蓝色圆点相对轨道右偏约 4px：为 WebKit 音量滑块圆点增加 `translateX(-4px)`，390px 手机、320px 窄屏和桌面宽度下圆点中心与轨道中心均已重合。
- 修复 LX 音源宿主将 `setTimeout` 回调同步立即执行的问题：此前所有带超时的 `lx.request` 在请求真正发出前就被取消，导致 QQ 音乐、酷我音乐、酷狗音乐取链全部失败；现在只立即执行 0ms 回调，正常延时交给 Java HTTP 请求超时处理。
- 修复 LX 音源宿主暴露响应头的方式：把 Java `Map/List` 转为 JavaScript 可读的字符串键值对象，音源对音频 `content-type` 的校验不再误判为“返回的不是音频”。
- 使用本地上传的“轻量音源（四平台多源并行）v2.1.0”复测：导入测试通过，QQ 音乐、酷我音乐、酷狗音乐、网易云音乐四个平台均可取到播放地址并在前台实际播放。
- 同步更新版本号至 1.20.10。
