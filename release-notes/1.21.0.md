# 博客 1.21.0 · 纸面编辑部

## 重新设计

- 前台整体改为「纸面编辑部 / 印刷技术刊物」视觉：暖纸、炭墨与单一朱红信号色，中文衬线大标题，去掉旧的蓝色渐变与等高白卡模板。
- 首页改为满幅封面 Hero、非对称编辑精选（主稿 + 双栏侧稿）、档案式文章行、深墨「索引与留白」信息带与统计数字带。
- 文章详情改为杂志式开篇：大标题、deck、作者行、16:9 全幅封面与 FIG 图注、204px 侧边目录 + 780px 窄阅读栏、衬线正文、H2 顶线分节、朱红引用线与深墨代码块。
- 关于页改为 About / Colophon 版式：左侧联系与数字栏，右侧衬线正文、首字下沉与 END 标记。
- 导航改为「站点首字印章 + 站名 + INK JOURNAL」字标；页脚改为三栏编辑式页脚，含巨型站名、浏览 / 连接栏、Issue 编号与版权行。
- 通知中心统一为档案台版面：墨色索引卡、朱红信号线、编辑式筛选与档案列表；详情弹窗改为直角纸卡与衬线内容。

## 视觉资产

- 新增 6 张编辑摄影风封面：编辑静物、技术手稿、深夜书桌、笔尖墨迹、印刷工坊、清晨书桌，统一暖纸 / 墨 / 朱红与低饱和质感。
- 图片压缩为 webp 放入 `frontend/src/assets/editorial-*.webp`，单张约 48–172KB；`frontend/src/covers.js` 按标签匹配封面，Hero 固定使用编辑静物封面。

## 体验与适配

- 新增完整的浅色 / 深色设计 token：纸色、墨色、辅助文字、边线、信号红与反色文字 `--ed-on-signal`，避免深色模式下暗字压红底。
- 新增响应式规则，覆盖 1180 / 1024 / 900 / 760 / 420px；手机端 Hero、编辑精选、文章页、关于页、通知页与弹窗重新排版。
- 首页索引摘要改为纯文本清洗，去掉原始 Markdown 标记；关于摘要按三级标题截断，避免技术栈长列表挤压版面。
- 保留搜索、通知、主题菜单、用户菜单、手机菜单、音乐悬浮球、AI 总览、评论、点赞与收藏等既有交互。

## 构建

- 版本升至 1.21.0，前端重新构建并打包进后端 jar。
- 已复查桌面首页、编辑精选、索引区、文章页、关于页、标签筛选页、通知中心与详情弹窗，以及手机首页、文章页、通知页与弹窗的浅色 / 深色表现。
