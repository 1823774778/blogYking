# 博客 1.20.2 · 长青音源兼容与播放检测

这次更新处理导入“长青SVIP音源 1.3.0”后暴露的问题：部分平台名称显示成 `kg音乐` / `tx音乐`，酷狗榜单点播时 `id=undefined`，以及音频地址失效时播放器无限重试。

## 音源兼容

- 音源把平台名写成 `kg音乐`、`tx音乐` 这类代码占位时，前台改为显示“酷狗音乐”“QQ 音乐”等正常名称。
- 音源里的自定义名称原样保留，例如六音音源的“企鹅音乐”不会被改成“QQ 音乐”。
- 榜单标题跟随修正后的名称，例如“酷狗音乐 TOP500”“QQ 音乐热歌榜”。
- 播放地址解析不再只认五个固定平台代码，改为校验当前音源实际声明的平台。
- 解析酷狗榜单时，同时把歌曲 hash 放进 `musicInfo.hash`，不再向音源传 `songmid` 导致 `id=undefined`。

## 导入检测

- 导入音源时不再“拿到地址就算通过”，会真实请求一小段测试音频。
- 测试音频返回 522/404/超时时，后台显示“播放测试未通过”并给出具体状态，不再误报播放测试通过。
- 六音音源等正常音源仍显示“音源播放地址测试通过”。

## 播放失败处理

- 音频地址失效后只自动重试一次，不再无限循环刷新代理地址。
- 重试仍失败时停止加载，并提示“音乐无法播放，请检查音源是否可用后重试”。

## 已知情况

- “长青SVIP音源 1.3.0”的音频后端 `yinyue.haitangw.net` 当前对播放请求返回 HTTP 522（源站超时）。这是音源服务端问题，站点无法替代其音频解析；导入时现在会明确提示。
- 六音音源不受影响，平台名称、榜单与播放仍正常。

## 验证记录

- 长青音源平台显示：酷狗音乐 / QQ 音乐 / 网易音乐 / 酷我音乐 / 咪咕音乐。
- 酷狗榜单标题“酷狗音乐 TOP500”，点播地址包含真实 hash，不再是 `undefined`。
- 长青音源导入测试返回“测试音频地址不可用：HTTP 522”。
- 六音音源导入测试仍通过，`tx` 仍显示“企鹅音乐”。
- 音频地址失效时只重试一次，随后停止并显示错误。
