## 博客 1.4.0

### 后台体验

- 后台内容区改为自适应铺满，宽屏下减少左右空白，表格、卡片与编辑器可用空间更大。
- 补齐深色模式遗漏：统计胶囊、搜索框、表格表头、状态标签、模型列表、AI 结果区、OTA 提示卡、弹窗表单与存储页面统一适配。
- 移除仪表盘、文章、评论、用户、个人信息、站点信息、编辑器与站点设置页顶部的大标题块，改为轻量工具栏。
- 配置类内容改为摘要卡 + 按钮 + 弹窗：SMTP、AI 设置均不再长期展开表单。
- 修复弹窗遮罩只覆盖内容区的问题，弹窗打开时顶栏与侧栏同步压暗。

### 站点更新

- 新增 GitHub Release 在线更新：后台可直接从最新 Release 下载 `blog.jar`，无需手动上传。
- 下载后自动校验 Spring Boot 启动类、应用配置与 SHA-256；校验通过才写入待更新区并提示更新。
- 在线下载仅接受 `github.com` / `*.githubusercontent.com` 的 HTTPS Release 资产，限制 100 MB。
- 本地上传保留为按钮 + 弹窗，放在“在线更新”旁边；移除站点更新页“当前运行”和“更新流程”侧栏。
- 当前运行信息并入“运行维护”，展示版本、构建时间、运行时长、实例、jar 大小、PID、数据库、Redis 与 SHA-256。

### AI 能力

- AI 设置模型名称旁新增“获取模型”：从当前 Base URL 读取可用模型，点击结果即可回填。
- 新增 AI 文章：编辑器内按主题、提纲、风格与篇幅生成草稿；生成后可继续人工修改。
- 新增 AI 文章审核：编辑器与文章管理均可调用，返回评分、结论、问题与修改建议。
- 新增 AI 评论审核：对单条评论给出建议通过 / 人工复核 / 建议拒绝、风险与理由，可一键采纳处理。
- 新增 AI 评论总结：后台按文章汇总评论区并持久化，前台文章详情评论区上方展示总结与生成时间。

### 注册与账号

- 新增注册开关：关闭后前台注册页显示“注册暂未开放”，后端同步拒绝注册请求。
- 开放注册时可强制邮箱验证码：6 位验证码、10 分钟有效、同邮箱 60 秒冷却、最多 6 次尝试。
- 邮箱验证码依赖已启用的 SMTP；未配置 SMTP 时接口明确返回不可用原因。

### 存储管理

- 侧栏新增“存储管理”，包含本地存储与线上存储。
- 本地存储支持查看文件数、占用空间、缩略图、访问地址、分页与删除。
- 线上存储支持 S3 兼容服务：Endpoint、Bucket、Region、Access Key、Secret Key、公开访问域名、路径前缀与 path-style。
- 密钥保存后不回显，留空代表沿用旧值；提供 `HeadBucket` 连接测试。

### 验证

- 后端 Maven `-DskipTests package` 成功，版本探针返回 `1.4.0`。
- 前端 Vite 生产构建成功，静态资源正常加载。
- 真实 H2 实例验证：配置读取、存储列表/删除、模型获取、AI 文章生成/审核、评论审核、评论总结持久化。
- 从 GitHub Release `v1.3.0` 实测在线下载 `blog.jar`：下载 64,995,637 字节，版本识别与 SHA-256 校验通过，待更新区写入成功。
- 浏览器实测浅色/深色后台、SMTP 与 AI 弹窗、设置页与工具栏布局。

### 下载

- `blog.jar`：完整可执行包，Java 17+，`java -jar blog.jar`。
- `blog.jar.sha256`：SHA-256 校验文件。

### 边界说明

- 线上 S3 存储已完成接口与配置页，真实连通性取决于服务商与凭据。
- 邮箱验证码已完成发送与校验链路，实际收信需要可用 SMTP 服务器。
- GitHub API 未认证时受每小时 60 次限额影响，部署时可配置 `GITHUB_TOKEN` 提升额度。
