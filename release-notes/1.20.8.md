# 博客 1.20.8 · 底部固定播放胶囊、仅已播放列表与竖音量条

- 播放器的歌曲胶囊、播放进度、上一首 / 播放暂停 / 下一首与音量入口统一移到底部固定区域，切换歌单、排行榜、搜索或播放列表时都不随内容滚动，始终可以控制当前歌曲。
- 播放列表改为只显示已经开始播放的曲目：点击“播放全部”时队列内部仍保留全部待播歌曲，但列表只展示当前已播放和此前播放过的记录，未开始播放的曲目不再铺开；切歌后新播放的曲目会追加到列表。
- 播放列表数量同步改为已播放曲目数；已播放状态随队列持久化，刷新页面后仍能识别当前曲目。
- 移除播放列表内常驻的横向音量条，改为点击底部声音图标才展开的竖音量条；再次点击或点击外部、按 Esc 收起，竖条内保留静音切换，音量值继续持久化。
- 缩小播放器尺寸：桌面宽度 392px → 364px，收紧头部、标签、列表行与底部栏间距；移动端改为四周留 8px 的底部弹层，不再完全贴边。
- 当前有歌曲时隐藏重复的底部来源提示，把最底部空间留给播放胶囊；无歌曲时仍保留来源与能力提示。
- 保留上一版真实平台名、完整歌单、跨源自动接续与列表行内暂停能力。
- 同步更新 README 与版本号至 1.20.8。
