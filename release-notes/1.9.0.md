# 博客 1.9.0

## 这一版更新了什么

- **默认主题重做**：移除 Firefly 主题的大横幅、玻璃胶囊、头像渐变与旧侧栏素材，换成接近 Halo 的简约主题：冷灰底、白卡、细边框、墨绿单一强调色。
- **首页重新排序**：站点简介与搜索、最新/热门与标签、文章流与分页依次排列；右侧保留关于、标签、热门文章与站点统计，并把文章卡改为更适合阅读的两栏结构。
- **后台视觉中性化**：顶栏与侧栏改为石墨色，内容区改为浅灰工作台，统一卡片、表格、按钮和状态表达，去掉薄荷绿渐变。
- **三档外观切换**：全站主题按钮改为下拉菜单，可选浅色、深色、系统；系统模式会跟随操作系统外观变化，并保存用户偏好。
- **邮件页重构**：邮件模板编辑和实时预览移到 SMTP 页面，配置弹窗只保留发信参数与测试；“配置邮箱”按钮固定在页面右上角。
- **站点更新精简**：更新内容默认展开；下载中只显示进度条，不再显示下载字样；移除上次更新；历史版本改为工具栏按钮并弹窗展示。
- **代理设置简化**：移除默认 ghfast 和“切换为直连”，代理前缀留空即直连。
- **后台入口收敛**：去掉右上角“查看站点”，只保留主题菜单，减少重复导航。

## 升级说明

- 直接替换 `blog.jar` 并重启即可，H2 / MySQL 数据会保留。
- 已用过的主题偏好会沿用；首次访问默认使用“系统”外观。
- 1.9.0 会沿用 1.8.0 的邮箱注册、互动通知和 OTA 能力，不需要额外迁移。
