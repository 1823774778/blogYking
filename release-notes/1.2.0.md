## 博客 1.2.0

### 新增

- 后台「更新」页接入 GitHub Releases，直接读取 `1823774778/blogYking` 的最新版本、发布时间与更新内容。
- 历史版本列表支持展开查看每个版本的完整更新说明，并提供 GitHub Release 与 jar 下载入口。
- GitHub 发布信息带 10 分钟缓存；读取失败时回退到上一次成功缓存，并显示错误原因与缓存时间。

### 改进

- 更新成功并重启后，页面会自动重新计算「当前已是最新 / 可更新」，不需要手动刷新。
- README 增加 GitHub Release 发布步骤、`GITHUB_TOKEN` 限额说明和 Release 读取接口。
- 新增 `scripts/release-github.sh`：发布 jar、SHA-256 与更新说明到 Releases。

### 验证

- 使用 GitHub Release 模拟数据验证最新版本、历史版本、Markdown 更新内容、刷新与错误回退。
- 前端 `vite build`、后端 Maven 打包通过，jar 启动后 Release 接口可正常返回。

### 下载

- `blog.jar`：完整可执行包，Java 17+，`java -jar blog.jar`。
- `blog.jar.sha256`：SHA-256 校验文件。
