# 博客 1.20.5 · 平台真实歌单与三列宫格

- 前台“歌单”不再把各平台榜单包装成歌单，改为读取当前音源平台的真实推荐歌单。
- 支持网易云、QQ 音乐、酷狗、酷我、咪咕五个平台的歌单列表；各平台结果交错排列，避免又变成按平台分组的假歌单。
- 歌单宫格改为三列真实封面，标题最多两行，并显示来源平台与歌曲数；点击卡片进入该歌单的歌曲列表。
- 歌单详情支持读取歌单名、封面、创建者、简介与歌曲列表：网易云、QQ、酷狗、酷我单份歌单最多读取 100 首，咪咕按接口返回读取。
- 新增 `GET /api/music/playlists?limit=` 与 `GET /api/music/playlist?platform=&id=`；保留旧版 `/api/music/playlist?url=` 兼容。
- 歌单列表与详情缓存 10 分钟，并按当前音源隔离，切换音源不会串用上一份歌单。
- 保留 1.20.4 的播放失败跨源接续：原始歌名严格相等、歌手集合匹配，排除 Live、黑胶、网友改编、合唱与多歌手版本。
- 同步更新 README 与版本号至 1.20.5。
