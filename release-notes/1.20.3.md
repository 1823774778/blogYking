# 博客 1.20.3 · 更新检查动效与音源驱动播放器

这次继续把站点音乐交给当前 JS 音源驱动，同时补齐后台更新页的操作反馈。

## 更新页

- “检查更新”现在有明确的加载动效：旋转刷新图标、按钮扫光、主色高亮，并在请求期间禁用，避免重复点击。
- 检查完成或失败后自动恢复为可点击状态；`prefers-reduced-motion` 下关闭旋转与扫光。
- 当前版本号仍以 JAR manifest 为准，下载、安装、历史版本的原有流程不变。

## 音源能力接口

- `GET /api/music/platforms` 新增 `source` 聚合对象：名称、版本、描述、作者、主页、初始化提示、平台数、榜单数、搜索数、音质与 actions。
- 新增顶层 `qualities`、`actions` 汇总字段；平台名称、音质和动作全部从当前 LX 音源脚本读取。
- 长青春源等只声明 `musicUrl` 的音源不会再被前端补出不存在的平台。

## 前台播放器

- 平台标签由横向滚动改为自适应网格：5 个平台在桌面和手机弹窗内都能完整换行显示，不再裁切。
- 头部音源摘要超过 2 个平台时显示“N 个平台”，悬停可看到完整平台名；音源名和版本保留在副标题。
- 新增音源能力条：显示音源声明的音质（如 128K / 320K / FLAC）和初始化提示。
- 音质优先采用接口 `source.qualities`，接口不可用时回退到已保存的音源配置。
- 修复切换音源后旧榜单短暂残留：切换时清空榜单缓存，并给音源能力请求加序号，避免旧响应覆盖新状态。
- 修复音源能力请求失败后“读取音源能力…”一直不消失的问题；失败时使用已知中文平台名兜底，不凭空补平台。

- 后台更新页验证检查态图标旋转、按钮扫光、禁用态可读；完成后恢复。
