# 博客 1.12.0

## 站点设置扩展

这次把后台三个设置页一次性补齐：AI 页收敛，注册页变成完整注册策略，运行维护页从“只看状态”升级为可操作的控制台。

### AI 设置

- 移除“模型连接”和“运行状态”两张概览卡。
- 保留 AI 启用状态、能力开关、提示词入口和配置弹窗，页面聚焦到实际可用项。

### 注册设置

- 新增密码找回独立开关。
- 新增邀请码注册，邀请码只在服务端校验。
- 新增邮箱域名白名单，支持 `example.com` 和 `*.company.com`。
- 新增密码最小长度，作用于注册、改密和重置密码。
- 新增用户总数上限。
- 新增新用户审核：开启后账号默认禁用，需管理员在用户管理中启用。
- 新增关闭自动登录：注册成功但不签发登录凭证。
- 新增注册公告、注册成功提示、关闭注册提示、新用户默认简介。
- 注册页同步展示邀请码、公告和动态密码长度；待审核与不自动登录时显示独立成功页。

### 运行维护

- 新增维护模式与自定义维护提示，后端过滤器强制拦截公共 API。
- 新增只读模式：可浏览，但发布、评论、点赞、收藏、改资料和上传会被拒绝。
- 新增运行与数据快照：文章、草稿、待审、评论、用户、标签、文件、堆内存和运行时长。
- 新增 JSON 数据导出，包含文章、评论、标签和脱敏用户资料，不含密码哈希与密钥。
- 新增更新缓存清理入口，复用 OTA 缓存清理能力。
- 保留原有版本、构建时间、实例、jar、PID、数据库、Redis 和重启站点。

### 后端与前端

- `SiteConfigService` 扩展注册、密码找回和站点模式配置键。
- `AuthService` 落实邀请码、域名白名单、密码策略、人数上限、审核与自动登录策略。
- 新增 `SiteModeFilter`，维护模式返回 503，只读模式返回 403。
- 公共站新增维护页和只读提示条。
- 登录与找回密码按独立开关联动。

### 验证

- 注册邀请码错误、域名不在白名单、密码不足、关闭注册等错误路径通过。
- 待审核注册返回无 token 且账号禁用；管理员启用后可登录。
- 关闭自动登录注册返回无 token，但账号可直接登录。
- 维护模式公共 API 返回 503，后台接口正常；只读模式写接口返回 403。
- 数据导出返回 200，包含文章、评论、标签、脱敏用户，不含密码字段。
- 桌面与手机注册页、维护页、只读提示均通过实际页面检查。
