# 博客 1.14.0

## 后台导航重构、文章编辑器重做与音乐歌单

本版按参考项目 [lingview/dim_stack](https://github.com/lingview/dim_stack) 的后台文章编辑器结构重做新建文章页，并集中优化后台导航、公告管理与站点音乐。

### 后台导航

- 侧边栏改为两级结构：一级固定为「仪表盘 / 个人中心」。
- 「内容」二级分组：文章管理、评论管理、标签管理、公告管理、主题管理。
- 「设置」二级分组：用户管理、角色权限、站点信息、通知设置、存储管理、站点设置。
- 折叠侧栏时隐藏分组标题，以图标栏展示全部二级入口，新增统一导航图标组件 `AdminNavIcon`。

### 新建文章页

- 按 `dim_stack` 的编辑器结构重做为白底全屏：顶部标题、同步滚动、取消、保存；左栏工具栏 + Markdown 编辑区，右栏实时预览。
- 文章信息由侧边抽屉改为居中弹窗，集中处理标题、摘要、标签、分类、别名、状态、封面、置顶与评论开关。
- 新增编辑历史撤销/重做（Ctrl/⌘+Z、Ctrl/⌘+Y）、选区浮动工具条、标题级别菜单。
- 支持粘贴与拖拽上传图片/附件，自动插入 Markdown；无封面时首张正文图片自动作为封面候选。
- 保留 AI 生成文章、AI 审核、AI 摘要与 Ctrl/⌘+S 保存。

### 公告管理

- 改为单卡片公告工作台：标题、展示状态与操作按钮统一头部。
- 前台展示开关与 AI 能力状态并排展示；标题/链接字段对齐。
- 编辑与预览固定等高双栏，新增实时预览卡、字数统计、LIVE 标记与底部说明。
- 保留插入图片、AI 生成公告、保存公告与原有公告接口。

### 存储设置

- 移除 S3 兼容存储选项与表单，存储方式只保留本地存储、WebDAV、OpenList。
- 旧配置为 S3 时，后台加载自动回落到本地存储。

### 站点音乐与歌单

- 新增音乐来源：单曲音频 / 平台歌单。
- 内置网易云音乐、QQ 音乐、酷狗音乐、酷我音乐、自定义平台；粘贴分享链接自动识别平台。
- 网易云与 QQ 音乐歌单使用官方 iframe 内嵌播放；酷狗、酷我与其他平台提供「打开歌单」入口。
- 后台新增歌单名称、平台徽标、播放器预览与使用说明。
- 前台音乐悬浮球重做：平台色圆形悬浮球 + 可展开播放面板，包含封面/平台标识、播放控制、进度条、时间、均衡器、歌单 iframe 与平台跳转。

### 构建与验证

- 前端 `vite build` 与后端 Maven 打包通过。
- 已在测试站验证：侧边栏展开/折叠、公告管理、存储方式选项、新建文章保存跳转、网易云歌单内嵌、QQ 音乐歌单内嵌。
