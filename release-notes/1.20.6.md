# 博客 1.20.6 · 搜索页、排行榜与平台歌单下拉

- 顶部常驻搜索框移入“搜索”页，切到搜索标签时自动聚焦，歌单与排行榜页不再占用搜索空间。
- 新增“排行榜”标签，读取当前平台 `/api/music/charts?limit=20` 的榜单，支持刷新、播放全部与点歌；从榜单点歌后停留在排行榜，不再自动跳到播放列表。
- 歌单页原来的平台小标改为可点击下拉：展开后分“推荐歌单 / 排行榜”两组，可切换小枸音乐（酷狗）、小蜗音乐（酷我）、小秋音乐（QQ）、小芸音乐（网易云）、小蜜音乐（咪咕）。
- 每个平台提供独立歌单列表与排行榜入口；选择“歌单”读取该平台推荐歌单，选择“排行榜”读取该平台榜单。
- 歌单页标题改为当前平台别名，不再显示“来自 N 个平台的 30 个歌单”。
- 排行榜标题同步使用平台别名，例如“小枸音乐 TOP500”，不再暴露真实平台名。
- 歌单、排行榜与搜索点歌均保持当前视图；播放全部也停留在原页面。
- 后端 `/api/music/playlists` 新增可选 `platform` 参数，指定平台时只读取该平台歌单，缓存按音源隔离。
- 修复移动端下拉菜单样式被重复写入媒体查询的问题；手机端菜单宽 214px，十个平台入口完整展示。
- 同步更新 README 与版本号至 1.20.6。
