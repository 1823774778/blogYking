# 博客 1.20.14 · 更短悬浮胶囊与音源平台搜索

- 桌面端悬停展开的音乐胶囊由 292px 缩短到 248px，封面、歌名、作者与 40px 播放按钮排列更紧凑；长歌名与作者继续单行省略，触屏与窄屏仍保持 54px 圆形悬浮球。
- 站内搜索不再固定网易云曲库，改为搜索当前音源脚本声明的可搜索平台；后端按音源实际平台并行检索，单平台失败不影响其他平台。
- 多平台结果按平台轮流合并并按歌名 + 歌手去重；每条结果携带平台标识，前端在歌手行显示来源平台，底部说明搜索覆盖的平台数量。
- 音源未声明可搜索平台时返回明确提示；音源声明平台与本站已适配平台取交集，不会凭空补平台。
- 版本升至 1.20.14。
