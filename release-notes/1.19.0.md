# 博客 1.19.0 · 本地音乐、音源持久化与全站播放器

这次更新把站点音乐拆成「本地音乐」和「音源导入」两个入口，补上本地 `.js` 音源上传、导入状态持久化和全站悬浮球，同时修复首页导航与播放器入口。

## 本地音乐

- 后台「站点音乐 → 本地音乐」支持一次选择多个音频上传，单首上限 30MB。
- 支持 MP3、FLAC、M4A、WAV、OGG、AAC、Opus。
- 文件名带「歌手 - 歌名」时自动拆分标题和歌手；没有时使用默认歌手。
- 上传后可直接改名、改歌手、隐藏 / 显示、删除；删除会同时清理本站存储中的音频文件。
- 前台播放器新增「本地音乐」视图，支持单曲播放和播放全部，不依赖外部音源。
- 本地音乐不依赖在线音源，音源失效时仍然可以播放。

## 音源导入

- 保留地址导入，新增本地 `.js` 音源脚本上传；两种方式导入成功都会立即保存。
- 上传脚本会复制到本站 `music-sources` 缓存目录，重启后直接加载，不再依赖原地址。
- 音源地址、名称、版本、平台、音质、验证状态、验证时间和脚本缓存路径写入站点配置，重启后保留。
- 同一已验证地址再次导入时跳过重复下载和测速，直接沿用上次验证结果。
- 运行缓存 TTL 从 30 分钟提升到 6 小时，首次下载后的脚本会写入本地缓存。
- 修复导入后只在前端更新、后端配置未立即持久化的问题。
- 后台不再显示默认的「填入六音音源地址」快捷入口，地址输入框保持空白，由管理员自行导入。
- 增加「移除音源」，清除地址、验证状态和脚本缓存配置，不影响本地音乐。

## 播放器与前台

- 音乐悬浮球在公开页面和管理后台都会显示；登录页、文章页、后台设置页切换不会打断播放。
- 只配置本地音乐、没有在线音源时，首页也会显示悬浮球，默认打开「本地音乐」。
- 后台布局修复后，播放器 `z-index` 高于后台顶栏和侧栏，仍低于后台弹窗。
- 播放器顶部标签根据能力显示：有音源时展示「本地音乐 / 热歌榜 / 播放列表 / 搜索」，纯本地模式只展示「本地音乐 / 播放列表」。
- 本地音乐队列刷新页面后仍保留播放地址，可直接继续播放。

## 首页与后台修复

- 修复首页顶部导航栏消失：补上 `App.vue` 中缺失的 `isAdminArea`、`showPublicChrome`、`showFooter` 等模板变量。
- 管理后台不再套用前台 `<main>` 布局，直接渲染后台路由页面。
- 后台「更新」页把「安装后会短暂断站」的回滚说明从待安装卡片底部移到卡片顶部。
- 后台站点音乐页重做为双模式布局，左侧编辑、右侧预览和使用说明，窄屏自动单列。

## 接口

- 新增公开接口 `GET /api/music/local`。
- 新增后台接口：
  - `GET /api/admin/music/local`
  - `POST /api/admin/music/local/upload`
  - `PUT /api/admin/music/local/{id}`
  - `DELETE /api/admin/music/local/{id}`
  - `POST /api/admin/music/source/upload`
- 原有 `/api/music/source`、`/api/music/search`、`/api/music/url`、`/api/music/charts` 调用方式不变。

## 升级说明

- 版本号升级至 `1.19.0`。
- `local_music` 表由 JPA 自动创建，不需要手工迁移。
- 旧版已保存的六音音源配置会继续保留；首次重新导入后会补上 `musicSourceStatus=verified` 和脚本缓存。
- 本地音乐文件保存在本站上传目录；云端存储模式下删除只清理站点元数据，不主动删除远端对象。
- 本地音源脚本缓存位于 `<local-storage>/music-sources`，升级时不要清理该目录，否则需要重新上传脚本。
