## 博客 1.5.0

### 首页导航

- 头像与深浅色按钮左侧新增通知按钮，显示未读数量；下拉展示已发布通知，支持置顶、类型与时间。
- 新增向左展开的导航搜索：输入关键词后模糊匹配文章标题、摘要与标签，结果直接下拉展示。
- 支持回车打开第一条结果，也可进入首页查看全部搜索结果。

### 后台管理

- 侧边导航新增“通知设置”和“标签管理”。
- 通知设置支持标题、内容、类型（信息 / 更新 / 系统）、置顶、发布状态、编辑与删除；未发布通知只保存在后台。
- 标签管理支持名称、颜色、排序、Slug、描述、前台显示、编辑与删除。
- 文章保存时自动把标签同步进标签目录；标签改名或删除会同步更新全部文章。
- 启动时自动回填旧文章标签，兼容从 1.4.x 升级的数据库。

### AI 设置

- AI 文章、AI 评论、AI 摘要各增加独立开关，状态保存到数据库。
- 新增五类数据库默认提示词：文章生成、文章审核、评论审核、评论总结、文章摘要。
- 后台 AI 设置、编辑器、文章管理、评论管理在发起 AI 操作前均展示可编辑提示词弹窗。
- 提示词支持恢复默认；AI 子功能关闭时对应操作会提示先开启功能。

### 站点更新

- 移除站点更新页全部“本地上传 jar”入口与上传弹窗，仅保留 GitHub Release 在线更新。
- 最新 Release 的“更新内容”默认收起，可点击展开；历史版本继续支持展开与收起。

### 注册设置

- 修复“注册必须验证邮箱”开关无反应的问题。
- 注册开关与邮箱验证开关可独立切换并保存；后端每次按数据库配置判断是否要求邮箱验证码。

### 数据存储

- 新增 `notifications`、`tags` 数据表。
- 通知、标签、AI 开关与提示词均通过后端读写数据库，后续新增配置沿用相同模式。

### 验证

- 后端 Maven `-DskipTests package` 成功，前端 Vite 生产构建成功。
- 全新 H2 实例完成初始化与接口验证：标签自动回填、通知公开读取、AI 默认提示词、注册邮箱开关持久化。
- 浏览器验收首页通知与导航搜索、后台 AI 设置与提示词弹窗、注册设置、站点更新折叠、标签管理与通知管理。

### 下载

- `blog.jar`：完整可执行包，Java 17+，`java -jar blog.jar`。
- `blog.jar.sha256`：SHA-256 校验文件。

### 升级说明

- 直接替换 `blog.jar` 后重启即可，Hibernate 会自动创建新增的 `notifications` 与 `tags` 表。
- 已有文章标签会在启动时自动写入标签目录，不需要手工迁移。
- 原有的文章、评论、用户、AI 与存储配置保持不变。
