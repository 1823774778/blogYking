# 博客 1.9.1

## 这一版更新了什么

- **后台主题同步**：顶栏、侧栏、二级导航和用户区都会随浅色 / 深色 / 系统模式切换，不再固定为深色。
- **更新页可主动检查**：没有新版本时，右上角按钮改为“检查更新”，点击会重新读取 GitHub Releases；失败时显示“重新检查”。移除了冗余说明文案。
- **SMTP 配置弹窗重做**：拆成“发信服务器 / 发件身份”两栏，加密方式改为可选卡片，补充常用服务商参数与测试发信区域。
- **发件身份语义修正**：SMTP 登录账号直接作为发件地址；原“发件人地址”改为“发件人名称”，只控制收件箱显示称呼。
- **全新邮件模板**：注册验证码、找回密码、测试邮件改为三套克制的编辑风格模板；旧的 1.8 默认模板会在启动时自动迁移。
- **AI 设置页重做**：改为 AI 工作台布局，包含连接概览、运行状态和三项能力卡片；开关、提示词入口与测试连接集中呈现。

## 升级说明

- 替换 `blog.jar` 并重启即可，H2 / MySQL 数据保留。
- 旧版默认邮件模板会自动替换；完全自定义的模板不受影响。
- SMTP 登录账号必须是完整邮箱地址，发件人名称留空时使用站点名。
