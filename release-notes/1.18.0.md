# 博客 1.18.0 · LX 音源导入与完整音乐播放器

这次更新把站点音乐从“云端歌单解析”改成“导入 LX Music 自定义音源”，并用导入的音源解析播放地址；前台悬浮窗重做成接近完整音乐 App 的播放器，支持搜索、队列、音量和四种播放模式。

## 音源导入

- 后台「站点音乐」移除旧的单曲/歌单来源切换，改为一个音源脚本地址输入框，内置“填入六音音源地址”入口。
- 新增「导入并校验」：后端下载并解析 LX Music 2.0 音源脚本，初始化后展示音源名称、版本、说明、支持平台、可用音质和测试曲目结果。
- 默认音源地址为六音音源 `1.2.1`：
  `https://gh-proxy.org/https://raw.githubusercontent.com/pdone/lx-music-source/main/sixyin/latest.js`
- 音源脚本在 GraalJS 沙箱中执行，不开放 Java 类、文件系统、子进程和线程；网络请求统一走受限的 `lx.request` 宿主。
- 兼容六音实际调用的 AES 参数顺序、带原始 JSON 的 QQ 请求 URL 和 JSON 响应对象，解决初始化失败、`Invalid AES key length`、`Illegal character in query` 等问题。
- 音源运行结果缓存 30 分钟；更换地址或手动重新校验时强制重新下载并重建运行时。

## 搜索与播放地址

- 新增公开接口：`GET /api/music/source`、`GET /api/music/search?keyword=&limit=`、`GET /api/music/url?id=&source=wy&quality=320k`。
- 新增后台接口：`GET /api/admin/music/source/preview?url=&refresh=`。
- 站内搜索使用网易云公开曲库，再交给导入音源解析播放地址；搜索缓存 2 分钟，并增加备用搜索接口与一次重试，降低平台限流导致的失败。
- 播放地址优先由音源解析；网易云曲目在音源未返回地址时回退到网易云公开播放接口。
- 付费、VIP 或版权受限曲目仍遵守平台限制，前端会给出“暂时无法播放”的提示，不绕过版权校验。

## 前台音乐播放器

- 悬浮球展开为完整播放器：搜索框、搜索建议、结果列表（封面、歌名、歌手、专辑、时长、VIP 标记）、播放队列和当前播放卡。
- 支持播放/暂停、上一首/下一首、进度拖动、音量滑杆、静音、移除单曲、清空队列。
- 支持四种播放模式：列表循环、单曲循环、随机播放、顺序播放；点击模式按钮循环切换并提示当前模式。
- 播放队列、当前索引、音量和播放模式写入本地存储；刷新页面后恢复队列，点击播放时按需重新解析地址。
- 收起面板后显示跨页迷你播放条；移动端使用底部全宽面板，支持 `Esc` 关闭。
- 搜索请求带序列号，旧请求不会覆盖新结果；解析播放地址时显示加载状态，失败时给出可读提示。

## OTA 与兼容

- 由于引入 GraalJS，fat jar 从约 95MB 增至约 182MB。
- OTA 上传上限从 100MB 提高到 240MB，请求上限 250MB，同步调整后端校验、GitHub Release 下载校验和后台提示。
- 旧的 `/api/music/playlist` 与旧后台预览接口保留兼容，但新前台不再使用云端歌单。
- 反向代理若设置了 `client_max_body_size`，需要同步放宽到 250MB 以上，否则浏览器上传会在代理层被拦截。

## 升级说明

- 版本号升级至 `1.18.0`，数据库结构无需迁移；新增的音源配置键会自动补充默认值。
- **首次从 1.17 及更早版本升级时，旧版本的 OTA 上限仍是 100MB，无法直接上传 182MB 的新包。请手动替换一次 jar 并重启；从 1.18.0 起 OTA 上限已提高到 240MB。**
- 六音音源当前实测可初始化 `kw/kg/tx/wy/mg` 五个平台；站内搜索固定使用网易云曲库，播放地址由音源解析。
- 网易云免费曲目（如 `1883571160` 白青《慢慢喜欢你》）已实测可搜索、解析并播放；付费曲目 `541687281` 返回 `-110`，属于平台版权限制。
- 六音 `tx` 平台在无 cookie 环境下可能返回空地址，`kw/kg/mg` 的完整播放链路取决于音源提供方和第三方代理稳定性，前端会按失败处理。
