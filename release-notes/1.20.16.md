# 博客 1.20.16 · 访问域名、导航管理与后台布局整理

## 站点访问域名

- 后台「站点信息」新增「访问站点域名」，支持只填域名、带端口或子路径，保存时统一补全 `https://` 并去掉末尾斜杠。
- 找回密码链接、邮件模板底部站点链接改为读取后台域名；未配置域名时回退到启动参数 `app.site-url`。
- 拒绝非 HTTP(S) 协议、账号信息、查询参数、锚点和空白字符，避免生成邮件链接时夹带异常内容。
- SMTP 邮件模板预览也跟随站点域名实时生成，不再固定显示示例地址。

## 通知页对齐

- 修复通知表格「创建时间」单元格被全局 `.meta` 的 Flex 布局接管，导致时间列与操作列基线不一致的问题。
- 表格改为固定布局并显式列宽，表头、时间、操作列严格对齐。
- 工具栏去掉外层大边框，搜索框、类型筛选、操作按钮统一为 40px 高，左右分布更整齐。

## 存储设置

- 移除「文件分类文件夹」卡片和分类统计，页面上不再单独展示图片 / 音频 / 视频等文件夹入口。
- 存储方式改为页面上的摘要卡片 + 「配置存储方式」按钮，点击后弹窗编辑 provider、Endpoint、用户名、密码、路径前缀、公开访问域名等配置。
- 弹窗使用独立草稿，取消不会污染当前配置；密码留空保持已保存值；支持 Escape 关闭和焦点回位。
- 「测试连接」保留在摘要卡片和弹窗中，可直接测试当前配置或弹窗草稿。

## 音源脚本只保留最新

- 上传本地 LX 音源 JS 后自动删除历史脚本，仅保留最新上传文件。
- 应用启动时执行一次历史脚本清理，并与后台配置的当前脚本对齐。
- 本地音源运行时直接复用 `upload-<hash>.js`，不再额外生成 `source-<hash>.js` 副本，避免脚本在运行中重新堆积。

## 前台导航管理

- 后台新增「导航管理」页，可新增、编辑、显示 / 隐藏、上移 / 下移、删除前台顶部导航标签。
- 支持站内路径与 `http(s)` 外链、是否在新窗口打开；最多 8 个标签，至少保留一个可见项，地址与名称均有长度校验。
- 前台顶部导航改为读取配置动态渲染，保留图标、激活态和移动端横向滚动，保存后无需重启。

## 关于页

- 默认「关于」内容更新为当前项目介绍，覆盖项目定位、技术栈、已有能力与写作动机。
- 首页右侧「关于这里」同步展示新的项目介绍。

## 构建

- 版本升至 1.20.16，前端重新构建并打包进后端 jar。
- 测试站已完成登录、导航增删、域名归一化、找回密码链接、音源上传只保留最新脚本等验收。
