# 博客 1.20.7 · 真实平台名、完整歌单与自动切源播放

- 平台下拉移除“小枸音乐 / 小蜗音乐 / 小秋音乐 / 小芸音乐 / 小蜜音乐”等前台别名，直接显示当前上传音源声明的平台名称。实测六音音源显示为酷我音乐、酷狗音乐、企鹅音乐、网易音乐、咪咕音乐。
- 歌单与排行榜合并为同一个“切换平台”入口：每个平台只出现一次，不再出现两组长相相同的菜单；在排行榜里切换平台会继续打开该平台榜单，在歌单里切换则打开该平台歌单，当前平台在两个视图之间保持。
- 歌单详情改为完整读取：网易云按 `trackIds` 批量补全，QQ、酷狗、酷我、咪咕按各自分页字段继续翻页，直到达到音源返回的曲目总数；实测酷狗 140/140、酷我 101/101、QQ 66/66、网易 114/114、咪咕 172/172，另有 646 首网易歌单在前台完整显示 646 行。
- 修复部分歌曲点击后无法播放：`/api/music/url` 支持歌曲名、歌手、专辑与时长，后端把这些字段补进 LX `musicInfo` 后再解析；原平台失败时，自动在其他可用平台按同歌名、同歌手寻找可播放版本，成功后在播放器提示“已自动切换到企鹅音乐播放”等实际平台。
- 播放队列保留切换前的原始来源与曲目 ID；自动切源后，原列表中的那一行仍能正确识别为当前播放歌曲。
- 歌单、排行榜、本地音乐与搜索结果统一支持行内暂停：正在播放的行显示暂停双竖线按钮，再次点击暂停；暂停后恢复播放三角；解析播放地址时显示加载圈。
- 延长大歌单详情请求超时到 90 秒，避免几百首的歌单在前台加载时被 30 秒超时截断。
- 同步更新 README 与版本号至 1.20.7。
