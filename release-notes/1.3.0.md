## 博客 1.3.0

### 新增

- 初始化向导连接 MySQL 时，数据库不存在会自动创建 `utf8mb4` 库，不再需要提前在 MySQL 中手工建库。
- 连接测试会检测目标库已有表数量：空库提示重启后自动建表并写入初始化数据；已有库提示自动更新表结构并保留已有数据。
- 初始化生成的 MySQL 连接串带 `createDatabaseIfNotExist=true`，目标库被删除时重启也能自动重建。

### 修复

- MySQL 旧库升级时，启动阶段自动把 `posts.content` 的非 `LONGTEXT` 类型升级为 `LONGTEXT`，避免长文章写入时报 `Data truncation`。
- 初始化向导补充建库权限、已有库更新和 H2 数据迁移边界提示。

### 验证

- 真实 MariaDB 10.6：连接不存在的库自动创建，重启后自动建表、创建管理员并写入 4 篇演示文章。
- 已有库删除 `users.bio` 后重启，字段自动补回，用户与文章数据保留，原管理员可正常登录。
- 旧版 `posts.content=TINYTEXT` 的库重启后自动升级为 `LONGTEXT`。

### 下载

- `blog.jar`：完整可执行包，Java 17+，`java -jar blog.jar`。
- `blog.jar.sha256`：SHA-256 校验文件。
