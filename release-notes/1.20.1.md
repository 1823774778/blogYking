# 博客 1.20.1 · 播放器内容完全跟随音源能力

这次更新把前台音乐弹窗的平台和入口改成由当前音源实时决定，不再固定展示网易云、QQ 等平台，也不会在音源没有榜单能力时强行显示榜单。

## 平台列表

- 新增公开接口 `GET /api/music/platforms`，读取当前导入音源声明的 `sources`。
- 平台代码、名称、actions、音质均来自音源脚本，例如音源里写“企鹅音乐”就显示“企鹅音乐”，不再由前端写死成“QQ 音乐”。
- 只有带 `musicUrl` 能力的平台会进入前台列表，音源没有声明的平台不会补出来。
- 前端平台标识颜色改为按平台代码生成，不再维护固定平台颜色表。

## 榜单

- 榜单标签只在音源声明的平台中，且本站有对应榜单适配时显示。
- 音源没有任何可用榜单平台时，整个“榜单”入口和榜单视图隐藏。
- 榜单标题使用音源里的平台名称拼接，例如“企鹅音乐热歌榜”，不再固定写“QQ 音乐热歌榜”。
- 平台切换顺序沿用音源声明顺序，不再从固定平台列表里补位。

## 搜索

- 站内搜索当前由网易云公开曲库承接。
- 当前音源没有声明网易云时，搜索输入框和“搜索”标签一并隐藏，避免搜索出无法用当前音源播放的歌曲。
- 搜索提示里的曲库名称改为当前音源里的平台名称。
- 音源没有榜单也没有搜索能力时，播放器只保留“播放列表”和队列控制，不再显示空入口。

## 兼容与兜底

- 音源能力接口读取失败时，回退到已保存的平台代码，不凭空增加平台。
- 已保存平台代码只用于接口失败兜底；正常情况一律以音源脚本返回的平台为准。
- 本地音乐模式不变，仍只显示本地音乐与播放列表。

## 验证记录

- 六音音源：前台显示“酷我音乐 / 酷狗音乐 / 企鹅音乐 / 网易音乐 / 咪咕音乐”，名称来自音源。
- 模拟仅 QQ（企鹅音乐）：只显示“榜单 / 播放列表”，搜索入口隐藏。
- 模拟仅酷我：只显示“榜单 / 播放列表”，不出现 QQ、网易云。
- 模拟仅 JOOX（无榜单适配、无网易云）：只显示“播放列表”，榜单和搜索都不显示。
- 模拟仅网易云且无榜单适配：只显示“播放列表 / 搜索”，默认进入搜索。
- 模拟空平台列表：只显示“播放列表”，不会回退成固定五平台。
- 榜单接口返回“企鹅音乐热歌榜”，搜索提示显示“搜索网易音乐曲库”。
- 网易音乐榜单播放正常，音频仍走同源代理。
