# 博客 1.8.0

## 这一版更新了什么

- **技术栈升级**：Spring Boot 4.2、MyBatis 4.1、Tailwind CSS 3.4，登录态支持 HttpOnly Cookie。
- **注册更直接**：邮箱就是用户名，不再填写用户名和昵称；新增本地离线图形验证码。
- **邮箱验证联动**：关闭邮箱验证后可直接注册，同时停用找回密码，避免出现无法发信的入口。
- **邮件工作台**：SMTP 页面只保留配置按钮，弹窗内左侧编辑、右侧实时预览，内置三套好看的 HTML 邮件模板。
- **互动通知**：点赞、收藏、评论自动进入仪表盘通知卡；版本更新也会自动发布通知。
- **界面校准**：注册、找回密码、SMTP 和仪表盘统一了间距、卡片层级与状态表达。

## 升级说明

- 直接替换 `blog.jar` 并重启即可；H2 / MySQL 数据会保留。
- MySQL 旧库会自动把 `users.username` 扩宽到 128 字符。
- 首次以 1.8.0 启动时会自动发布一条更新通知；之后同版本重启不会重复发布。
